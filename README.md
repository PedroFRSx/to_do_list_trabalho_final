A ideia é fazer um To-Do List. Um aplicativo que ajuda o usuário a se organizar.

## Funcionalidades

1. Cadastro de tarefas.
2. Prioridades.
3. Agenda diária.
4. Controle de conclusão.
5. Lembretes de 5, 15 ou 30 minutos dentro do app.

## Telas

1. Perfil do usuário. A tela é acessada pelo avatar em Hoje e permite editar o nome.
2. Hoje. Resumo do dia, com tarefas pendentes, concluídas e atrasadas.
3. Cadastro e edição das atividades, acessíveis pela tela Hoje.
4. Calendário. Visualização das tarefas por data.
5. Progresso. Taxa de conclusão, totais e lista de tarefas concluídas com filtros por semana, mês ou todo o período.
6. Lembretes. Configuração de avisos para tarefas futuras, alteração da antecedência, reagendamento e desativação.

A tela Hoje apresenta informações como:

- Quantas tarefas o usuário tem para hoje.
- Quantas estão pendentes.
- Quantas já foram concluídas.
- Quantas estão atrasadas.
- Qual é a próxima tarefa.

As tarefas, as configurações de lembrete e o nome do usuário são salvos automaticamente no aparelho ou no navegador. Os avisos aparecem enquanto o app está aberto.

## Vamos usar a API Nager.Date

A API fornece informações sobre feriados de diversos países, incluindo o Brasil.

Possibilidade: mostrar feriados na agenda e ajudar o usuário a planejar suas tarefas.

Exemplo:

- Próximo feriado.
- Feriado nacional.
- Informação obtida pela API de feriados.
